A program that writes one Wi-Fi network name of at most 32 characters to `/output/entry.txt` — a name that lands a joke and implies a whole story in the few words a passer-by sees in a phone's network list.

The name is **"Our WiFi Outlived The Marriage"** (30 characters). A marriage ended, and the one thing that survived it is the home Wi-Fi: the router is still broadcasting, the relationship is not. Two people, a shared home, a marriage that ran its course — and the network name is the dry little epitaph left behind, still visible to every neighbour scanning for a signal. No stock Wi-Fi wordplay, no slogan: just a punchline that reads exactly like a real network name a stranger would screenshot.

## Run it

```sh
node main.ts
```

This writes the network name to `/output/entry.txt` (creating `/output` if needed).
